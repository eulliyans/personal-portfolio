EULLIYAN’S PERSONAL PORTFOLIO — STARTER

FILES
- index.html: page structure
- style.css: all visual styling and responsive breakpoints
- data.js: editable profile, project and social-link content
- script.js: renders the data and handles the mobile navigation

HOW TO CUSTOMIZE
1. Open data.js.
2. Change profile.displayName, profile.roles and profile.intro.
3. Change each project name, description and link.
4. Replace each social URL with your real public link.
5. Keep private information, passwords, API secrets and Private Vault data OUT of this public repository.

IMPORTANT
- Links currently set to "#" are placeholders, not live links.
- The portrait, QR code and project thumbnails are visual placeholders. Add your own approved image assets and a real QR code before launch.
- No Private Vault page or private data is included in this public starter.
- Test on mobile and desktop before publishing.
